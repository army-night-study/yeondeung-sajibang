# 사이버지식정보방 연등

육군 생활관 사이버지식정보방(사지방)의 밤 연등 시간(22:00–24:00)을 three.js로 만든 3D 웹페이지입니다.

- 접속한 사람마다 들어온 순서대로 `용사1`, `용사2`… 이름이 붙고, 사지방 하나에 24명까지 앉을 수 있습니다. 넘치면 다음 사지방으로 이동합니다.
- 버튼: 경례, 앉기/일어서기, 친구 부르기, 전체 보기. 자유 채팅은 없고, 머리 위에 짧은 "지금 하는 일"만 보입니다.
- **친구 부르기**는 `#코드`가 붙은 주소를 만듭니다. 그 주소로 들어온 사람끼리만 같은 사지방에 앉습니다.
- 앉으면 오늘의 목표 2가지를 내 모니터에 적을 수 있습니다(내 브라우저에만 저장).
- 21:30, 22:00–23:50(30분마다 한마디), 23:50에 시간대별 공지가 나옵니다.

## 동시 접속 방식

- GitHub Pages에서는 [Trystero](https://github.com/dmotz/trystero)로 브라우저끼리 WebRTC로 직접 연결합니다. 서버가 없고, 서로를 찾을 때만 공개 Nostr 릴레이를 씁니다.
- claude.ai 아티팩트에서는 아티팩트의 room 기능을 씁니다.
- 둘 다 연결되지 않으면 가상의 용사들과 함께하는 오프라인 체험으로 시작합니다.

## 파일

- `index.html` — 페이지 원본(claude.ai 아티팩트용, 문서 머리 없이 내용만)
- `build.ps1` — `docs/`에 GitHub Pages용 완성본을 만듭니다
- `docs/` — GitHub Pages가 보여주는 폴더
- `moon/` — 달 텍스처

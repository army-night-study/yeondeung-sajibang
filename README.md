# 사이버지식정보방 연등

육군 생활관 사이버지식정보방(사지방)의 밤 연등 시간(22:00–24:00)을 three.js로 만든 3D 웹페이지입니다.

- 접속한 사람마다 들어온 순서대로 `용사1`, `용사2`… 이름이 붙고, 사지방 하나에 24명까지 앉을 수 있습니다. 넘치면 다음 사지방으로 이동합니다.
- **소속 고르고 입장:** 처음 들어오면 소속을 골라야 입장합니다(육군 1·2·3·5·7·수도군단, 2작전사·수방사·특전사·육군 직할, 해군·공군·해병대·국직부대). 보안을 위해 사단 이하 실제 부대명은 받지 않습니다. 이름 앞에 소속이 붙습니다(예: `3군단_용사1`, 이름표·시간판·안내 문구·이름 버튼). 소속은 접속 상태에 실려 가고, 시간판에 "오늘 군단별 합계"(지금 접속한 사람의 오늘 시간 총합)가 나옵니다. 이름 버튼(✎) → 소속 바꾸기로 바꿀 수 있습니다. 월간 베스트 부대(한 달 총합)는 접속을 끊은 사람의 시간까지 모아야 해서 서버(Supabase)를 붙인 뒤에 뽑습니다.
- 아래 줄의 이름 버튼(✎)으로 닉네임(최대 8자)을 바꿀 수 있습니다. 비우면 다시 `용사N`이 되고, "용사+번호"는 남의 번호와 헷갈리지 않도록 쓸 수 없습니다.
- 서 있을 때는 방향키·WASD(화면 기준 방향)나 바닥을 눌러 걸어 다닐 수 있습니다. 책상·컴퓨터·의자가 있는 책상 섬과 벽은 지나갈 수 없고, 바닥을 누르면 섬을 돌아가는 길을 찾아 걷습니다. 빈 자리를 누르면 그 자리까지 걸어가서 앉습니다. 내 위치는 접속 상태 메시지에 실려 초당 최대 8번 다른 사람에게 갑니다.
- **행보관 순찰:** 22:10("딴 짓 안하나 보러왔다"), 매일 바뀌는 22:15–23:44 사이 한 번(대사 없음), 23:50("이제 슬슬 정리해라..")에 행보관(상사)이 오른쪽 벽(시계·충성 포스터 옆)의 문을 열고 들어와 닫은 뒤 사지방을 한 바퀴 돌고, 다시 문을 열고 나가 닫습니다. 시각과 위치는 날짜와 시계로 정해져서 모두에게 같은 때 같은 자리로 보입니다. 주소에 `?patrol=1`(또는 2, 3)을 붙이면 그 순찰을 바로 볼 수 있습니다.
- **지금 가장 오래 연등한 용사:** 오른쪽 벽(창가 쪽) 판에 지금 접속한 사람을 누적 시간 순으로 보여 줍니다. 공개 사지방이면 모든 사지방, 친구 방이면 친구들만 나옵니다. 판을 누르면 전체 목록이 열립니다. 시간은 각자 기기에서 화면을 켜 둔 동안 재고(숨긴 탭은 제외), 서버가 없으니 지금 접속한 사람만 보입니다.
- **부대 바깥:** 사지방은 2층짜리 생활관 동의 2층 한쪽 끝 방이고(문밖 계단참에서 바깥 계단이 1층 마당으로 내려갑니다)(카메라 쪽 두 벽은 허리 높이로 잘린 모형처럼 보입니다), 주변에 도로와 연병장, 뒤편 2층 생활관, 국기 게양대, 가로등, 철조망과 위병소, 소나무, 산 능선이 있는 밤하늘/낮하늘이 있습니다. 다른 생활관은 22:00에 소등하고 당직실만 불이 켜져 있습니다. 카메라는 부대 밖으로 나가지 않게 막았습니다.
- 버튼: 경례, 앉기/일어서기, 친구 부르기, 전체 보기. 자유 채팅은 없고, 머리 위에 짧은 "지금 하는 일"만 보입니다.
- **친구 부르기**는 `#코드`가 붙은 주소를 만듭니다. 그 주소로 들어온 사람끼리만 같은 사지방에 앉습니다.
- **집중 타이머:** 모든 PC석 모니터 위쪽에 22:00–24:00 두 시간 타이머가 있습니다. 남은 시간(시:분:초), 자정까지 남은 분, 지금까지 집중한 분과 더 집중할 분, 진행 막대를 보여 줍니다. 22:00 전에는 시작까지 남은 시간, 자정이 지나면 완료를 표시합니다. 기기 시계를 따르므로 모두에게 같은 시간이 보입니다.
- **21:59 취침나팔:** 페이지를 열어 둔 사람에게 21:59에 취침나팔 소리(`sound/bugle.mp3`, 만든 사람이 직접 녹음)를 한 번 들려줍니다. 브라우저 정책상 페이지를 한 번이라도 누르거나 키를 눌러야 소리가 나옵니다. "지금 하는 일" 줄 끝의 🔔 버튼으로 이 기기에서 끌 수 있고(🔕), 주소에 `?bell=1`을 붙이면 화면을 누를 때 바로 들어 볼 수 있습니다.
- 앉으면 오늘의 목표 2가지를 내 모니터에 적을 수 있습니다(내 브라우저에만 저장).
- 21:30, 22:00–23:50(30분마다 한마디), 23:50에 시간대별 공지가 나옵니다.
- 21:00에 불이 켜지고 24:00에 꺼집니다. 꺼진 뒤에도 모니터는 켜져 있습니다.

## 연등 다이어리

종이 다이어리를 쓰고 그 페이지를 찍어 올리면, 날짜별 기록이 쌓입니다.

- **나의 기록** → **오늘 다이어리 인증하기**로 사진을 올리면 빨간 "연등 인증" 도장이 찍히고, 달력의 그날 칸에 사진이 붙습니다.
- 새벽 6시 전에 올리면 전날 기록으로 들어갑니다(연등은 자정을 넘기니까요). 하루에 한 장이며, 그날에는 다시 올려 바꿀 수 있습니다.
- 총 기록일, 연속 기록일, 이번 달 기록일을 보여주고, 날짜를 누르면 사진과 그날의 목표를 다시 볼 수 있습니다.
- 앉아 있으면 내 책상에 기록한 날 수만큼 초록 다이어리가 쌓이고, 가장 최근 페이지가 칸막이에 폴라로이드로 붙습니다.
- 사진은 브라우저(IndexedDB)에만 저장되고 어디에도 올라가지 않습니다. 다른 사람에게는 이름표에 "연등 기록 n일"만 보입니다.

## 정품 다이어리 인증 (QR)

실물 다이어리 표지 안쪽에 권마다 다른 QR을 인쇄합니다. QR을 찍으면 사이트가 열리면서 다이어리 기록 화면과 "정품 다이어리 인증" 도장이 뜨고, 이름표에 정품 배지가 붙습니다.

- QR 주소: `https://…/?d=일련번호.서명` (예: `YD26-000001.…`). 서명은 ECDSA P-256이며, 사이트는 `index.html`의 `DIARY_KEYS` 공개키로 확인합니다.
- `tools/qr-maker.html`: 내 PC에서 열어 서명 열쇠 파일을 고르고, 일련번호 범위를 정해 QR을 만듭니다. 결과는 목록 CSV(인쇄소 가변 인쇄용), QR SVG 묶음(ZIP), A4 스티커 인쇄 시트로 내려받습니다.
- 서명 열쇠(비밀 열쇠)는 이 저장소에 없습니다. 만든 사람의 PC에만 두고, 공유하거나 올리지 말고 따로 백업하세요.
- 한계: 서명은 위조 코드를 막지만, 같은 QR을 여러 사람이 찍는 것은 막지 못합니다. 막으려면 서버에 일련번호 등록 기록이 필요합니다.

## 동시 접속 방식

- GitHub Pages에서는 [Trystero](https://github.com/dmotz/trystero)로 브라우저끼리 WebRTC로 직접 연결합니다. 서버가 없고, 서로를 찾을 때만 공개 Nostr 릴레이를 씁니다.
- claude.ai 아티팩트에서는 아티팩트의 room 기능을 씁니다.
- 둘 다 연결되지 않으면 가상의 용사들과 함께하는 오프라인 체험으로 시작합니다.

## 파일

- `index.html` — 페이지 원본(claude.ai 아티팩트용, 문서 머리 없이 내용만)
- `build.ps1` — `docs/`에 GitHub Pages용 완성본을 만듭니다
- `docs/` — GitHub Pages가 보여주는 폴더
- `moon/` — 달 텍스처
- `sound/bugle.mp3` — 21:59 취침나팔 소리
- `tools/qr-maker.html` — 정품 QR 만들기(내 PC 전용)
